## 2. 필수 사용자 시나리오별 검증 결과

### 시나리오 1: 신규 게스트 계정 (아이디 가입)
- **절차**:
  1. `/api/auth/username`으로 아이디 `univ_student_01` 가입.
  2. 세션 수립 후 `get_or_create_trial_credits` 호출 시 **1회 크레딧** 부여 확인.
  3. 과목 및 강의자료 생성 후 AI 개념 분석 요청 시 크레딧 1회 차감 (잔여 0회).
  4. 잔여 0회 상태에서 추가 문제 출제 요청 시 `402 (TRIAL_CREDITS_EXHAUSTED)`로 차단 확인.
  5. 로그아웃 후 재로그인 시 크레딧 0회가 그대로 유지됨 확인.
- **결과**: **PASS** (`P02-08`, `P01-02` 검증 완료)

### 시나리오 2: 일반 사용자 (표준 계정)
- **절차**:
  1. Google OAuth 인증 세션 생성 시 기본 **3회 크레딧** 지급 확인.
  2. 과목 생성 → 자료 등록 → 개념 분석(1회 차감) → 고난도 문제 생성(1회 차감) → 답안 작성 및 평가(1회 차감).
  3. 평가 결과 및 루브릭 채점 내역이 `practice_attempts` 테이블에 원자적 스냅샷으로 저장됨 확인.
  4. 재로그인 후 복습 대시보드 및 망각곡선 추정치가 정상 복원됨 확인.
- **결과**: **PASS** (Stage 1~10 파이프라인 검증 완료)

### 시나리오 3: 개인 API 키 사용자
- **절차**:
  1. 설정 > 내 AI API 연결에서 개인 API 키 등록.
  2. 서버 DB에 AES-256-GCM 암호문으로 저장되고 마스킹 힌트(`sk-••••5678`)만 클라이언트에 반환됨 확인.
  3. 개념 분석 및 문제 생성 실행 시 운영자 체험 크레딧이 **0회 차감(잔여량 보존)** 됨 확인.
  4. 개인 키에 인증 오류가 발생했을 때 운영자 유료 API로 자동 전환되지 않고 즉시 개인키 오류로 보고됨 확인.
- **결과**: **PASS** (`AI 체험 크레딧 5`, `AI 체험 크레딧 6` 검증 완료)

### 시나리오 4: 장애 및 실패 복구
- **절차**:
  1. AI 게이트웨이 호출 전 실패 또는 네트워크 단절 시 `release_trial_credit`을 통해 예약된 크레딧이 즉시 환급됨 확인.
  2. AI 생성 성공 후 DB 저장 단계에서 장애 발생 시, 생성된 초안을 클라이언트 세션/로컬에 보존하고 `retry_save` 경로를 통해 추가 AI 호출 없이 DB 저장만 재시도 성공 확인.
  3. 중복 네트워크 전송으로 동일 작업이 재전송되더라도 DB 임대 락(`lease_token`)으로 중복 과금 차단 확인.
- **결과**: **PASS** (`AI 체험 크레딧 7`, `AI 체험 크레딧 8`, `결함 1` 검증 완료)

### 시나리오 5: PDF 변환
- **절차**:
  1. 일반 텍스트, 수식(LaTeX 표기), 다단 레이아웃 PDF가 브라우저 PDF.js 엔진으로 클라이언트에서 오류 없이 변환됨 확인.
  2. 텍스트가 없는 스캔/이미지 PDF 업로드 시 `422 PDF_NO_TEXT`와 함께 OCR 미지원 안내 출력 확인.
  3. 외부 Python 서비스 미구성 상태에서 GET `/api/convert` 호출 시 `available: false`와 함께 브라우저 엔진으로 자연스럽게 안내되어 애플리케이션 크래시 없음 확인.
- **결과**: **PASS** (`P02-05`, `PDF 변환 1~8` 검증 완료)
