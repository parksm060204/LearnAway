# Plan 06 — 03. 학습 대시보드 및 복습 우선순위 설계 (Learning Dashboard & Prioritization)

## 1. 대시보드 정보 구조 (Information Architecture)

대시보드는 대학생이 공부를 시작할 때 인지 부하 없이 "지금 당장 해야 할 공부"에 집중할 수 있도록 3단 계층형 구조로 설계되었다:

```mermaid
graph TD
    Dashboard[대시보드 메인: Today Workspace] --> Header[상단: 과목 선택기 + D-Day 배지 + AI 체험 크레딧]
    Dashboard --> QuickStats[1단: D-Day 카드 + 오늘의 복습 개요 + 취약 개념 경보]
    Dashboard --> ActionCard[2단: 오늘의 1순위 핵심 과제 (Primary CTA)]
    Dashboard --> ConceptList[3단: 개념별 기억 유지율 & 복습 추천 목록]
```

## 2. D-Day 산출 및 시험 단계별 전략 (`dateUtils.calculateDDay`)

LearnAway는 한국 표준시(Asia/Seoul, UTC+9) 캘린더 날짜를 기준으로 정밀한 D-Day를 계산한다:

### 2.1 상태별 D-Day 레이블 규격
- **미설정 (`isNotSet`)**: `'시험일 설정'` (클릭 시 시험일 등록 팝업 안내)
- **시험 당일 (`isToday`)**: `'D-Day'` (잔여 시간 `NNh` 표시)
- **시험 종료 (`isOverdue`)**: `'시험 종료'` (사후 총정리 및 다음 학기 대비 모드)
- **미래 시험일**: `'D-N'` (예: `D-5`, `D-14`)

### 2.2 D-Day 기반 학습 단계 (Phases)
1. **D-30 이상 (개념 완비기)**: 기본 개념 이해 및 Level 1~2 문제 풀이 집중.
2. **D-29 ~ D-8 (심화 전개기)**: 증명, 복합 추론, Level 3~4 전이 문제 및 취약 개념 집중 보완.
3. **D-7 ~ D-1 (직전 파이널)**: 실전 모의고사, 시간 제한 풀이 및 빈출 오답 유형 점검.
4. **D-0 (시험 당일)**: 핵심 정리 노트 요약 및 최종 공식 재확인 (신규 문제 생성 억제).

## 3. 오늘의 1순위 핵심 과제 (Primary Action CTA)

대시보드 상단에는 학생이 오늘 가장 먼저 실행해야 하는 단 하나의 행동을 명확히 제시한다 (`resolvePrimaryCta`):
- **진행 중인 모의고사가 있을 때**: `'모의고사 이어 풀기'` (기존 진행 세션 복원)
- **오늘 보류된 복습 문제가 있을 때**: `'오늘의 복습 풀이 시작 (N개)'` (우선순위 1위 문항 바로 진입)
- **오늘 복습이 완료되었을 때**: `'오늘의 복습 완료! 🎉'` 및 추가 심화 문제 생성 안내

## 4. 개인화 복습 우선순위 산정 알고리즘

복습 대상 목록은 무작위가 아닌, 다음 4가지 핵심 요소를 종합한 가중치 점수(`priorityScore`)에 의해 결정론적으로 정렬된다:

$$\text{PriorityScore} = w_1 \cdot (100 - \text{Retention}) + w_2 \cdot (100 - \text{Mastery}) + w_3 \cdot \text{ErrorFrequency} + w_4 \cdot \text{DDayUrgency}$$

1. **기억 유지율 결핍도 ($100 - \text{Retention}$)**: 망각곡선상 권장 복습 시점을 넘긴 개념 가산.
2. **개념 숙련도 결핍도 ($100 - \text{Mastery}$)**: 루브릭 평가 점수가 낮았던 개념 우선.
3. **학술 오류 빈도 ($\text{ErrorFrequency}$)**: 최근 3회 내 동일 학술 오류(개념 오류, 반례 간과 등) 반복 발생 시 우선순위 급상승.
4. **시험 D-Day 긴급도 ($\text{DDayUrgency}$)**: 시험일이 임박할수록 비중 증가.

## 5. 지표의 투명성: 설명 가능한 대시보드 (Explainable AI)

학생이 "왜 내가 오늘 이 개념을 공부해야 하는가?"라는 의문을 품지 않도록 각 항목에 구체적인 추천 사유를 노출한다:
- `"최근 풀이에서 '조건 누락/경계값 간과' 오류가 2회 연속 발생했습니다."`
- `"마지막 복습 후 5일이 경과하여 기억 유지율이 52%로 저하되었습니다."`
- `"선수 개념인 '행렬식(Determinant)'의 숙련도가 부족하여 역행렬 풀이 전 복습을 권장합니다."`
