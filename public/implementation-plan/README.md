## 변경 및 완료 보고 기준

각 단계 보고에는 실제 기준 SHA, 수정 파일과 동작, 실행한 검사, 원격 서비스 검증 여부, 제한 사항, 다음 단계 진입 조건을 적는다. Mock 검증과 실제 브라우저·DB·Gateway 검증을 구별한다. 데이터 삭제, 배포, 커밋, 푸시는 별도 요청 없이는 하지 않는다.

단계 완료 시 해당 단계 문서를 삭제하고 이 색인에서 링크와 행을 제거한다. 계획서 원본과 사용자 데이터는 삭제하지 않는다.
